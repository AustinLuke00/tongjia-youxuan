# 童价优选 — 第一版可运行演示

## 启动
直接双击 `index.html`，或在此目录运行：

```bash
python3 -m http.server 8080
```

然后访问 http://localhost:8080 。不需要安装 npm 依赖。

## 已实现
响应式首页、搜索、8 类商品分类、渠道筛选、价格排序、同款报价弹窗、收藏（浏览器 localStorage）、资质准入说明。

## 重要说明
全部商品、价格和渠道信息均为演示数据，不是真实商家、真实报价或已核验官方店铺。没有真实购买跳转。上线前必须接入获得授权的平台商品接口，建立店铺主体与品牌授权审核流程，且只发布审核通过、未过期的真实商品记录。

## 后续架构建议
Vue 3 + TypeScript 前端、Spring Boot API、MySQL 商品/商家/资质/报价表、Redis 缓存、定时价格同步、管理员审核后台。禁止将商家名称包含“官方”直接视作已认证。
